# EwokVPN

</div>

EwokVPN — кроссплатформенный прокси- и VPN-клиент на основе [sing-box](https://github.com/SagerNet/sing-box). Поддерживает VLESS, VMess, Reality, TUIC, Hysteria, WireGuard, SSH и другие протоколы, импортирует подписки sing-box, V2Ray, Clash и Clash Meta.

## Основано на Hiddify

EwokVPN — форк приложения **[Hiddify](https://github.com/hiddify/hiddify-app)** от команды Hiddify. Вся заслуга за исходное приложение принадлежит Hiddify и его участникам.

- Исходный проект: https://github.com/hiddify/hiddify-app
- Исходная лицензия: [Hiddify Extended GNU General Public License v3](https://github.com/hiddify/hiddify-app/blob/main/LICENSE.md)
- Ядро: [hiddify-core](https://github.com/hiddify/hiddify-core), используется без изменений под [собственной лицензией](https://github.com/hiddify/hiddify-core/blob/v3/LICENSE.md)

EwokVPN не связан с Hiddify и не одобрен командой Hiddify.

## Изменения относительно Hiddify

Полный список изменений ведётся в [README.md](README.md#changes-from-hiddify). Функциональность приложения пока не отличается от Hiddify, изменены только название, иконка, идентификаторы, ссылки и настройки сборки.

## Загрузка

Релизы публикуются на странице [Releases](https://github.com/HunterEwok/ewokvpn-hiddify-app/releases) и собираются только через GitHub Actions.

EwokVPN распространяется под той же лицензией, что и Hiddify, — [Hiddify Extended GNU General Public License v3](LICENSE.md), включая дополнительные условия: исходный код остаётся открытым форком Hiddify на GitHub, релизы собираются через GitHub Actions, коммерческое использование без письменного согласия команды Hiddify запрещено.
